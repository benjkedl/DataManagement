Structured vs Unstructured Data - Theory

Data Shapes Matter

The data you work with everyday is shaped in one of two ways: Structured Data and Unstructured Data. Read the module below to learn about these different structures, then apply your knowledge to the knowledge check on the following page!

Structured Data

Definition: Structured Data is data that is organized in a predefined format, typically arranged in rows and columns like a table or database.

Characteristics:
  • Organized in tabular (table) format
  • Fixed schema or structure
  • Easily searchable and queryable
  • Fits neatly into rows and columns
  • Machine-readable format
Examples:
  • Excel spreadsheets
  • Database Tables (OASIS)
  • CSV files
  • Most things with Rows and Columns

Unstructured Data

Definition: Unstructured Data is data that doesn't have a predefined format or organization, often containing free-form content that doesn't fit into traditional database structures.

Characteristics:
  • Difficult to search without processing
  • Rich in context and meaning
  • Requires specialized tools for analysis
Examples:
  • Email messages
  • Power Point Presentations
  • PDF documents
  • CANVAS page content
  • Word documents

Why This Distinction Matters

Understanding the difference between structured and unstructured data is crucial because:

  • Storage Requirements: Different types require different storage solutions
  • Processing Methods: Each type needs specific tools and techniques for analysis
  • Search (Query) Capabilities: Structured data is easily searchable, while unstructured data requires specialized processing
  • Data Quality: Structured data typically has higher consistency and quality

Data Types Overview - Theory

Core Data Types

Now that you understand the ways data is shaped when we work with it, lets examine each individual piece of data. Each piece of data has a specific type that tells the computer how to use it. For example, if data were food, the data type would be the food groups! Read about the different types of data below, then apply it on the following interactive activity.

Most Common Data Types for Plains & Alpine Summit

String

Description: Text data enclosed in quotes, used for names, descriptions, and textual information. In our work, we don't often see the quotations

Examples: "UCD47493", "John Doe", "T8"

Use Cases: Names, IDs, Emails, Room #s, Group #s, Text-entry survey answers

In Excel: Text entries, concatenation, lookup values (will talk more about this throughout our upskilling effort)

Integer

Description: Whole numbers without decimal points, used for counting and identification.

Examples: 42, -17, 0, 1000

Use Cases: Counts, IDs, quantities, rankings, years

In Excel: Mathematical calculations, Certain IDs within OASIS, indexing

DateTime

Description: Date and time values used for timestamps and temporal data.

Examples: 2024-07-01, 12:30:45, March 15, 2024

Use Cases: Timestamps, deadlines, schedules, historical data

In Excel: Date calculations, Automations to Outlook Calendar, scheduling functions

Less Common Data Types, but still important

Boolean

Description: Represents true/false values used for logical operations and conditions.

Examples: true, false

Use Cases: Status flags, conditional logic, yes/no questions, availability indicators

In Excel: Used for checkboxes, conditional formatting, and logical formulas

Float

Description: Numbers with decimal points, used for measurements and precise calculations.

Examples: 3.14159, 0.5, -2.75, 99.99

Use Cases: GPA, FTE, percentages, assignment grades

In Excel:statistical analysis, averages, credit calculations

Why Proper Data Typing Matters

  • Accuracy: Ensures calculations and operations work correctly
  • Efficiency: Optimizes storage space and processing speed
  • Validation: Prevents invalid data entry and errors
  • Functionality: Enables type-specific operations and functions
  • Automation: If automations see a data type where it shouldn't be, it will often fail
